# 训练数据上传接口（App ⇄ 自建服务）

对应 App 侧：**设置 → 训练数据采集**（默认关闭）与 `core/collect/`。
这份文档同时是"为什么这么设计"的说明 —— 采集屏幕内容这件事，产品上必须克制。

---

## 1. 设计底线（先看这个）

| 原则 | 落地方式 |
|---|---|
| **默认关闭** | 不打开开关就一帧都不采（`CollectPolicy.shouldCapture` 第一句就是 `enabled` 判断） |
| **可见** | 设置页显示"今日已采 N 张 / 待传 N 张 / 当前是否 Wi-Fi"；抓屏通知的状态行也会附带待传计数 |
| **有上限** | 采样间隔下限 5 秒（防止 2 帧/秒 ≈ **1.4 GB/小时**）、每日张数上限、每日流量上限 |
| **可停可清** | 随时关开关；"清空待传"一键删掉本地还没传的样本 |
| **先攒后传** | 断网/服务挂了不丢样本（比如隧道 530 期间照样采，恢复后自动补传） |
| **去重** | 手机侧用 64 位 dHash 近似去重（汉明距离 ≤6 视为同画面）；服务端再用内容哈希命名兜一层 |
| **仅 Wi-Fi（默认）** | 移动网络下只入队不上传 |

> 截图可能包含聊天记录、密码等私密内容 —— 这是"你自己决定要不要采"的功能，不是默认行为。

---

## 2. 接口

### `POST /collect`

复用检测服务的 **base 地址与 X-API-Token**（App 从内置凭据读，无需额外配置）。

请求：`multipart/form-data`

| 字段 | 类型 | 说明 |
|---|---|---|
| `source` | string | 来源，当前为 `screen` |
| `image` | file | JPEG（质量 80），文件名形如 `<dHash16位>_<时间戳>_screen.jpg` |

响应：`200`

```json
{ "ok": true, "saved": "20260925/screen/3f2a9c1b7d4e5f60.jpg", "total": 128 }
```

错误：`401` 令牌不对 / `413` 图太大 / `415` 类型不支持 / `400` 空文件。

### `GET /collect/stats`

按天统计已收样本数（便于你看"这一天收了多少"）：

```json
{ "days": { "20260925": 128 }, "total": 128 }
```

## 3. 服务端落地

见 `tools/collect_server.py`（FastAPI 片段）。挂进已有服务：

```python
from collect_server import router as collect_router
app.include_router(collect_router)
```

自检：

```bash
curl -X POST http://127.0.0.1:8000/collect \
     -H "X-API-Token: <你的token>" \
     -F source=screen -F image=@test.jpg
```

> 注意：隧道（api.kangxistar.top）恢复后，**这条路径才会真的通**。
> 在那之前 App 会一直把样本攒在本地 —— 这是有意设计，不是 bug。

## 4. 收完数据怎么用

### 4.1 先跑预标注（省掉大部分手工框选）

```bash
# 用你当前的模型给采集回来的图打预框，写成同名 YOLO txt（人只做修正）
python3 tools/prelabel.py --images ./collected --model runs/nekonyan/weights/best.pt --vis
# 顺带生成训练用的 data.yaml 骨架（类别顺序取自模型，别改）
python3 tools/prelabel.py --images ./collected --model best.pt --yaml dataset/data.yaml
```

`prelabel.py` 的行为：**幂等**（已有 txt 的图默认跳过，`--overwrite` 强制重打）、
按 `--conf`（默认 0.25）过滤低置信框、按 `--min-box` 丢掉过小的噪声框、
`--vis` 会把画框结果写到 `preview/` 供肉眼核对、**无目标的图保留空 txt**（背景负样本，压误检很有效）。
注意它写出的 `class_id` 用的是**模型自己的 names 顺序**，训练时必须沿用同一顺序。

### 4.2 修正并训练

1. 样本按 `日期/来源/` 落在 `collected/`；
2. 在预标注的基础上增删改（X-AnyLabeling / LabelImg 都能直接读这些 txt）；
3. 训练与导出见 [yolo_训练与接入.md](./yolo_训练与接入.md)；
4. 模型走**热更新**下发（`GET /model/latest`，App 侧会自动校验签名与类别数并支持回滚）。
